# Modelos de segmentación laboral

Repositorio asociado al Trabajo de Integración Final (TIF) sobre retornos a la educación y segmentación laboral en Argentina, 2017–2024.

El repositorio contiene el código utilizado para el procesamiento de los microdatos de la EPH-INDEC, la construcción de las variables, el análisis exploratorio, las estimaciones econométricas y la elaboración de tablas y figuras.

## Estructura del repositorio

- `Codigo/`: scripts utilizados para el procesamiento y análisis econométrico.
- `Figuras/`: figuras utilizadas en el análisis.
- `Output/`: resultados y tablas.
- `Paper/`: documentos asociados al TIF.

## Datos

Los datos utilizados corresponden a los microdatos de la Encuesta Permanente de Hogares (EPH) del INDEC para el período 2017–2024. Los microdatos no se incluyen en este repositorio.
