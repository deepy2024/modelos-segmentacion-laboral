# Modelo

Esta carpeta contiene el código y el análisis cuantitativo desarrollado para el Trabajo de Integración Final (TIF).

El notebook *Modelo de mercados segmentados.ipynb* contiene el procesamiento de los datos, la construcción de las variables, el análisis exploratorio y las estimaciones econométricas utilizadas en la investigación.

El análisis utiliza microdatos de la Encuesta Permanente de Hogares (EPH) del INDEC correspondientes al período 2017–2024.

Los microdatos originales no se incluyen en este repositorio.
